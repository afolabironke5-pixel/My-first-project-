My First Website Challenge 🌍✨

Overview
This project is a beginner-friendly React + Firebase app that combines:
- A login form powered by Firebase Authentication
- A fun facts feature that displays random facts

Features
- Firebase setup in MyFirstCode.js
- Login form and logic in App.js
- Rendering with index.js
- Root div and fun facts script in index.html

Setup
1. Clone the repository.
2. Run npm install to install dependencies.
3. Add your Firebase project credentials in MyFirstCode.js.
4. Run npm start to launch the app.

Usage
- Create a test user in Firebase Authentication.
- Log in with email + password using the form.
- Enjoy random fun facts displayed on the page.

Deployment
This project supports auto-deployment with GitHub Actions.
- Workflow file: .github/workflows/firebase-deploy.yml
- Runs on pushes to main branch
- Uses Firebase CLI and a secret token (FIREBASE_TOKEN)
